# GreenApi_testovoe

Веб-чат для мессенджера MAX через [GREEN-API](https://green-api.com/max): отправка и получение текстовых сообщений. Текст задания — в [TZ.md](TZ.md).

## Как запустить локально

1. Установите [Node.js](https://nodejs.org) версии 22.13 или новее (подойдёт и 24).
2. Скачайте проект и установите зависимости:

   ```sh
   git clone https://github.com/JulSannin/GreenApi_testovoe.git
   cd GreenApi_testovoe
   npm ci
   ```

3. Запустите:

   ```sh
   npm run dev
   ```

4. Откройте в браузере http://localhost:5173.

## Как войти

1. В [личном кабинете GREEN-API](https://console.green-api.com) возьмите `idInstance` и `apiTokenInstance` своего инстанса MAX. Инстанс должен быть авторизован: QR-код отсканирован в приложении MAX.
2. Введите их на странице входа.
3. Если сверху появилась плашка про выключенные уведомления, нажмите «Включить приём». Сообщения начнут приходить в течение 5 минут.
4. Введите номер собеседника, например `7 999 123-45-67`, нажмите «+» и напишите сообщение.

## Другие команды

| Команда           | Что делает                                      |
| ----------------- | ----------------------------------------------- |
| `npm run build`   | собирает сайт в папку `dist`                    |
| `npm run preview` | открывает собранный сайт: http://localhost:4173 |
| `npx vitest run`  | запускает тесты                                 |
| `npm run lint`    | проверяет код                                   |
